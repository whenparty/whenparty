# Claude Code

`.claude/` holds the Claude Code settings, hooks, skills and subagents of this repository. It is not a [project](/docs/glossary.md#project) and has no [specification](/docs/conventions/specs.md).

- [docs/configuration.md](/.claude/docs/configuration.md): which files of `.claude/` git tracks; what [settings.json](/.claude/settings.json) enables, allows, denies, asks to confirm and sets for Bash commands, and why; how a description decides when a skill or subagent is used; which tools the subagents have and which model `last-reader` runs on; which commands the `codex` skill runs without asking; and when a change takes effect. Read it before changing any file in `.claude/`.
- [docs/modern-web-guidance-setup.md](/.claude/docs/modern-web-guidance-setup.md): how each person installs Google's `modern-web-guidance` plugin for this repository and lets its commands run in auto mode.
- [docs/docs-weekly-setup.md](/.claude/docs/docs-weekly-setup.md): how to set up the scheduled task of the desktop app that starts the `docs-weekly` skill each week.
- [docs/rules-queue-merge-setup.md](/.claude/docs/rules-queue-merge-setup.md): how to set up the scheduled task of the desktop app that starts the `rules-queue-merge` skill each day.
- [docs/codex-setup.md](/.claude/docs/codex-setup.md): how to install OpenAI Codex CLI, sign in and create the profile that the `codex` skill runs it with.
- [hooks/AGENTS.md](/.claude/hooks/AGENTS.md): the hook scripts in `hooks/` that `settings.json` registers, how they work and how to test them, and an evaluation of whether agents read the [documents](/docs/glossary.md#document) a task needs before they edit, and whether they change the files it needs.
- [skills/decide/SKILL.md](/.claude/skills/decide/SKILL.md): the `decide` skill, which prepares a decision for the user when the [Decisions section](/docs/conventions/workflow.md#decisions) of the workflow says to stop.
- [skills/codex/SKILL.md](/.claude/skills/codex/SKILL.md): the `codex` skill, which gets an independent second opinion from OpenAI Codex CLI on a narrow task, such as a review of a diff, code, a specification or a plan.
- [skills/docs-weekly/SKILL.md](/.claude/skills/docs-weekly/SKILL.md): the `docs-weekly` skill, the weekly pass over the [documents](/docs/glossary.md#document): it counts their words, starts a session for each long document that regroups, cuts or splits it, cuts text that adds nothing, finds why documents grew, moves the parts of documents that sessions noted, proposes lessons for the writing rules and goes over the misunderstandings with the user. [weekly-pass.md](/docs/decisions/weekly-pass.md) is the decision record on why the pass runs on the user's Mac, which documents it changes before the user answers, why a split numbers requirements again and why each long document gets a session of its own; read it before changing any of these.
- [skills/rules-queue-merge/SKILL.md](/.claude/skills/rules-queue-merge/SKILL.md): the `rules-queue-merge` skill, which each day takes the changes of the rules of work that wait in the rules queue, as [Rule changes](/docs/conventions/workflow.md#rule-changes) says, into one change, has it checked and brings it to the user.
- [agents/docs-reviewer.md](/.claude/agents/docs-reviewer.md): the `docs-reviewer` subagent, which checks documents against the [conventions files](/AGENTS.md#conventions-files) for the reviews in [workflow-checks.md](/docs/conventions/workflow-checks.md).
- [agents/behaviour-reviewer.md](/.claude/agents/behaviour-reviewer.md): the `behaviour-reviewer` subagent, which checks how a modelled or specified system behaves, for the reviews that [workflow-checks.md](/docs/conventions/workflow-checks.md) and [workflow-specs.md](/docs/conventions/workflow-specs.md) require: of a behaviour model, of a specification edit that changes behaviour, against its model when it has one, and of a [state table](/docs/conventions/tests.md) that gained a state.
- [agents/findings-verifier.md](/.claude/agents/findings-verifier.md): the `findings-verifier` subagent, which tests the findings of a review against the text and confirms, changes or refutes each, as [Ending a review](/docs/conventions/workflow-checks.md#ending-a-review) says.
- [agents/spec-test-verifier.md](/.claude/agents/spec-test-verifier.md): the `spec-test-verifier` subagent, which checks every specification against its tests and back after the weekly pass splits a specification.
- [agents/last-reader.md](/.claude/agents/last-reader.md): the `last-reader` subagent, which reads a finished change and the draft report about it once before the user sees them, for the [last reading](/docs/conventions/workflow-checks.md#last-reading).
- [package-runners.md](/docs/decisions/package-runners.md): the decision record on why settings.json denies `npx`, `npm x`, `npm exec` and `pnpm dlx` but not `pnpx`, and why the denial is in the repository's settings. Read it before changing which package runners settings.json denies.
- [pnpm-deps-check.md](/docs/decisions/pnpm-deps-check.md): the decision record on why the `pnpm-workspace.yaml` of each folder with a `deps:cached` script sets `verifyDepsBeforeRun` to `warn`, so that the script that [settings.json](/.claude/settings.json) lets run without asking downloads nothing. Read it before changing that setting or adding the script to another folder.
- [web-guidance.md](/docs/decisions/web-guidance.md): the decision record on why agents read Chrome's Modern Web Guidance through Google's plugin and not a subagent of the repository, why its CLI runs the latest version with its telemetry off, why the plugin updates itself, where each person installs it, why auto mode needs an entry in each person's settings, and why no workflow file requires the guides. Read it before changing how agents get the guides, which version of the CLI runs, whether the plugin updates itself, where each person installs it, whether the CLI sends usage data, how its commands run in auto mode or whether a workflow file requires the guides.
