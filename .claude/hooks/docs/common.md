# What the hooks share

The hooks in `.claude/hooks/` are POSIX shell scripts that read the hook input as JSON on stdin. They need `jq`, and the hooks that act on files also `git`; without them they do nothing. The hooks that act on files act only on files of this repository and its worktrees that git does not ignore; ruleset-guard.sh acts on Bash commands. [repo-path.sh](/.claude/hooks/repo-path.sh) is not a hook: doc-context.sh and word-limit.sh source it to find the path of a file in the repository and to tell whether git ignores it. Claude Code cuts any text a hook adds to the context at 10,000 characters.
