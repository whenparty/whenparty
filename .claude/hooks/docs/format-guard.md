# format-guard.sh

[format-guard.sh](/.claude/hooks/format-guard.sh) runs before every Bash command. Before a `git commit`, it checks with Prettier the files that the branch changes and denies the commit when one of them is not formatted or Prettier cannot parse it, so a commit of an agent does not fail the `format` check of [checks.md](/.github/docs/checks.md#the-checks). Its reason lists the files and asks the agent to format them, add them and commit again.

The hook splits the command into parts at `;`, `|`, `&` and line breaks, as [ruleset-guard.md](/.claude/hooks/docs/ruleset-guard.md) describes, and splits each part into words at spaces, without parsing quotes. It starts in the folder that the hook input gives as `cwd` and follows each part that runs `cd <folder>` or `cd -- <folder>`. In a part that runs `git` and then `commit`, it follows each `-C <folder>` in order, skips the value of each `-c` and skips other options. It checks every such part until it denies one. A folder outside this repository and its worktrees passes, and so does a folder named with a space or a variable.

It checks, in the working tree of that folder, every file that differs from the commit where the branch left `origin/main`, or `main` when there is no `origin/main`, committed or not, and every file that git does not track and does not ignore, with `node_modules/.bin/prettier --list-different --ignore-unknown`. Prettier skips the files that [.prettierignore](/.prettierignore) lists and the files whose type it does not know, and formats as [.prettierrc.json](/.prettierrc.json) says. When the branch changes `.prettierrc.json`, `.prettierignore` or the root `package.json` or `pnpm-lock.yaml`, or no such commit is found, the hook checks every file of the working tree instead. It does not check what the commit will hold, so it also checks the changes that the commit leaves out.

When `node_modules/.bin/prettier` is missing in the root of the working tree, the hook denies the commit and asks the agent to run `pnpm deps:cached` there first. When the check takes longer than the 30 seconds that settings.json gives the hook, Claude Code lets the commit through, and only the `format` check of CI catches the files.

To test the hook, pass made-up `PreToolUse` inputs with `cwd` and `tool_input.command`, as [testing.md](/.claude/hooks/docs/testing.md) describes, from a working tree with and without an unformatted file that git does not track, and with `cd`, `cd --`, `git -c` and several `git -C` before `commit`, to folders inside and outside the repository.
