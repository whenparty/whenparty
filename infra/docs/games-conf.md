# Working on games.conf

`games.conf` holds two servers: one for the games and one for `signaling.when.party`. [nginx-configs.md](nginx-configs.md) says how it combines with the shared settings, and [game-hosts.md](/docs/decisions/game-hosts.md) explains why the games share one host and have a config of their own, and [games-routing.md](/docs/decisions/games-routing.md) why nginx reaches their containers itself.

- The server for the games names only `games.when.party`, where every title has a path of its own, as [hosting.md](/games/titles/docs/hosting.md) says. The former hosts of titles fall to the wildcard server of `temp-sites.conf`, as [former-game-hosts.md](/docs/decisions/former-game-hosts.md) decides.
- It passes a path `/<name>/...` to the container `games-<name>` on port 80, with `/<name>` removed, and every other path to the index page's container `index` through the upstream `games_index`. The server for `signaling.when.party` passes everything to the container `signaling` on port 8080 through the upstream `games_signaling`. [sites.md](sites.md) says how nginx finds these containers. [check-game-names.yml](/.github/workflows/check-game-names.yml) checks that the titles' containers and those that the upstreams name keep their names and the network `wp_games`, and that no other container takes them, as [checks.md](/.github/docs/checks.md#the-checks) says.
- It removes `/<name>` with `rewrite ... break` before `proxy_pass`, because nginx sends a path that a variable in `proxy_pass` builds without encoding it again, so a `%20` or `%3F` in it would reach the title decoded.
- The server for the games redirects a path of one segment of lowercase letters, digits and hyphens without a trailing slash, such as `/tictactoe`, to the same path with the slash, because the location of the titles matches only the path with it.
- The server for the games has a 404 page of its own in place of the shared one in [nginx-configs.md](nginx-configs.md). It turns every 404 that the index page or a title sends, and every 502 and 504, into `nginx/conf.d/errors/games-404.html` with status 404. nginx answers 502 when no container has the name of a path's title, so a path that names no title and a title whose container is down look the same. The page has `Cache-Control: no-store`, so Cloudflare does not keep a 404 from the seconds a title is redeployed. `infra.yml` copies that file with the rest of the folder. The page copies the colours and fonts of the index page's [styles.css](/games/index/src/styles.css), so a change to them there needs the same change in `errors/games-404.html`. A title that needs its own 404 body needs a location for its path with `proxy_intercept_errors off`. The server for `signaling.when.party` passes its responses on unchanged, so it answers 502 while the signaling server is down.
- The Content-Security-Policy of the server for the games lets the games reach the signaling server, over WebSocket and for their TURN credentials. A change to the policy of the temporary sites does not need the same change here. Both policies allow the Cloudflare Web Analytics script that Cloudflare adds to every page. The script reports to `/cdn-cgi/rum` on the page's own host, which `'self'` covers.
- The signaling server has its own limits per client address, in zones of its own. Every player holds one WebSocket there, and the players of one party often share an address, such as one Wi-Fi or a mobile carrier's NAT, so the 15 connections that the other sites allow would shut the 16th player out. Its own zones also keep those sockets from using up the 15 connections that the game pages get. The signaling server limits what each socket does, keeps its heartbeat below `proxy_read_timeout`, and relies on these limits, as the [signaling documentation](/games/platform/signaling/AGENTS.md) says.
- The Content-Security-Policy of the server for the games and the Permissions-Policy of `default.conf` are copied to `games/platform/p2p/src/dev-headers.ts` for local game development, with the local signaling server added, as the [p2p documentation](/games/platform/p2p/AGENTS.md) says.
