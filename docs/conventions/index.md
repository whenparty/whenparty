# Conventions

Each conventions file covers one kind of file:

- [Specification rules](specs.md): [module](../glossary.md#module) specifications and module `AGENTS.md` files.
- [Testing rules](tests.md): test files.
- [Code conventions](code.md): source code.
- [Documentation conventions](documentation.md): all other documents, and responses.

A rule lives in the file that covers what the rule constrains. Rules about how to work, such as the order of steps or when to stop and ask, live in the root [AGENTS.md](../../AGENTS.md).
