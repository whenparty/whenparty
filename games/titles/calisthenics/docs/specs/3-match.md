# Match

- `3-1` The room has 12 seats. In the lobby each seated player enters an athlete name of 1 to 20 characters after trimming spaces. Names may repeat.
- `3-2` The host can start the championship when 2 to 12 players are seated and every one of them has entered a name. Each of them, the host included, gets an athlete. No athletes are added later. A player without an athlete sees the championship but cannot act. Starting the championship opens the first challenge's announcement.
- `3-3` Each challenge has three screens:
  1. Announcement. Everyone sees only the challenge's number and name, so the players can talk about it. The host can open preparation.
  2. Preparation. Each athlete's player makes and confirms a plan ([1-2](1-preparation.md)). Once every athlete's plan is confirmed, the host can start the challenge.
  3. Results. Everyone sees, for each athlete, the levels this challenge's plan trained, its score, whether that is full or partial completion or not performed ([2-2](2-scoring.md)), and the reason for a score below 100. Everyone also sees the championship standings, and the host can open the next challenge's announcement. After the tenth challenge the results also show the winners, there is no next announcement, and the championship ends. No new championship starts in that room.
- `3-4` While an athlete's player is absent or has left the room, the host cannot move the championship to its next screen. An athlete whose player has left keeps no player, so the championship stays paused. The game itself never ends a championship before the tenth challenge. When a player counts as absent or as having left, and closing the room when the host leaves, follow the [platform's session rules](../../../../platform/p2p/STATES.md).
