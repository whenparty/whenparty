# Scoring

- `2-1` The championship has ten challenges in this order, each with the levels it requires:

  | Challenge | Required levels |
  | - | - |
  | 1. Push-ups | Arms 1, chest 1, stamina 1 |
  | 2. Squats | Legs 1, stamina 1 |
  | 3. Pull-ups | Arms 1, back 1, stamina 1 |
  | 4. L-sit | Arms 1, abs 1, stamina 1 |
  | 5. Pistol squat | Legs 2, balance 1, stamina 1 |
  | 6. Handstand | Arms 2, abs 1, balance 2, stamina 1 |
  | 7. Muscle-up | Arms 2, back 2, abs 2, balance 2, stamina 1 |
  | 8. Burpees | Arms 2, chest 2, legs 2, stamina 2 |
  | 9. Front lever | Back 3, abs 3, balance 2, stamina 2 |
  | 10. Human flag | Arms 3, back 3, abs 3, balance 2, stamina 2 |

- `2-2` An athlete's score for a challenge is 100 · Σ min(level, required) / Σ required over the required characteristics, rounded down. 100 is full completion, 1–99 partial completion and 0 means the challenge was not performed. Push-ups with arms 2, chest 1 and stamina 0 score 66.
- `2-3` The reason for a score below 100 names the characteristics below their required level.
- `2-4` An athlete's championship points are the sum of its ten scores. The athletes with the most points win the championship together.
