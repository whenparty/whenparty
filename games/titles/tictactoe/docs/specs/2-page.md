# Page

- `2-1` When a person opens the page at an address whose part after `#` the netcode does not turn into a room code ([2-4](../../../../platform/netcode/docs/specs/2-page.md)), or that has no such part, the page shows the lobby: a button that starts a game and a form that enters one by its room code.
- `2-2` When a person submits the form with text that the netcode does not turn into a room code, the form shows "That is not a room code. Codes have 5 characters, like K7MXQ." With text that it turns into a room code, the page enters that game.
- `2-3` When a person starts or enters a game, the page shows the room view: the status ([3-1](3-status.md)); the text "you host" when 2-13 says; the board with the marks of the last snapshot that the page took in the game ([2-10](../../../../platform/netcode/docs/specs/2-page.md)), or empty before the first one; and a button that leaves the game. Once the page has the room code, from the netcode when it started the game ([2-3](../../../../platform/netcode/docs/specs/2-page.md)) or from the address or the form when it entered one, the view also shows the code and a button "Copy invite link" that copies the invite link (2-14) to the clipboard (2-12).
- `2-4` When a person opens the page at an address whose part after `#` the netcode turns into a room code, the page enters that game.
- `2-5` When the part of the address after `#` changes to text that the netcode turns into the code of another game than the page's, the page leaves its game, if any ([2-11](../../../../platform/netcode/docs/specs/2-page.md)), and enters that game. When it changes to text that the netcode turns into the code of the page's game, the page only puts the code into the address in the form of 2-14. When it changes to text that the netcode does not turn into a room code, the page leaves its game, if any, and shows the lobby.
- `2-6` When a person presses the leave button, the page leaves the game, shows the lobby and removes the code from the address.
- `2-7` When a mark wins, its winning cells ([1-4](1-rules.md)) have a colour that no other cell has, until the next match starts.
- `2-8` When the page can act ([8-1](../../../../platform/netcode/docs/specs/8-actions.md)), its seat is to move ([1-2](1-rules.md)), the match is not paused ([1-6](1-rules.md)) and the cell is empty, clicking the cell makes the move. Otherwise clicking a cell does nothing. When the netcode tells that a move was refused, the page shows nothing of it.
- `2-9` When the host's page takes a snapshot ([2-10](../../../../platform/netcode/docs/specs/2-page.md)) in which no match has started ([4-2](../../../../platform/netcode/docs/specs/4-seats.md)) and both seats have players, it starts the first match ([5-2](../../../../platform/netcode/docs/specs/5-matches.md)). While the game ([2-1](../../../../platform/netcode/docs/specs/2-page.md)) goes on and, in the last snapshot that the host's page took, a match has started, no match runs and both seats have players, the host's page shows a button that starts the next match. When the netcode tells "cannot start", the page shows nothing of it.
- `2-10` While the game goes on, for each join request that the netcode tells the host's page of ([4-3](../../../../platform/netcode/docs/specs/4-seats.md)), the page shows "A player wants to join." with the buttons "Let in" and "Refuse", which answer it. It stops showing the request when it is answered, the netcode tells that it ended, or the game ends.
- `2-11` After starting or entering fails or the game ends ([2-1](../../../../platform/netcode/docs/specs/2-page.md) and [2-7](../../../../platform/netcode/docs/specs/2-page.md)), the room view stays until the leave button is pressed or the address changes as 2-5 says.
- `2-12` When a copy that the button of 2-3 started ends, the button reads "Copied", or "Copy failed" when the browser did not copy the link, until 2 seconds have passed since a copy last ended. Then it reads "Copy invite link" again.
- `2-13` While the game ([2-1](../../../../platform/netcode/docs/specs/2-page.md)) goes on, the room view shows the text "you host" when the page started the game, or when the netcode told, with the last snapshot that the page took in the game, that the page is the host's ([2-10](../../../../platform/netcode/docs/specs/2-page.md)).
- `2-14` Once the page has the room code of its game (2-3), it replaces its address, without a new history entry, with one that ends in `#` and the code in the form that the netcode gives ([2-4](../../../../platform/netcode/docs/specs/2-page.md)). The invite link is that address.
