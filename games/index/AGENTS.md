# Index

`index/` is the [subproject](/docs/glossary.md#subproject) that serves the page at the root of `games.when.party`, which lists the games. It is one [deployment](/docs/glossary.md#deployment).

- [docs/specs/](docs/specs/): what the page shows and which paths answer 404.
- [docs/page.md](docs/page.md): where the entries, pictures and styles live, how the router reaches the page, and what adding a game changes here. Read it before changing anything in `index/`.
- [docs/verification.md](docs/verification.md): the commands that build, test and typecheck the page, the smoke test of the image, and the local preview.
- [index-page-location.md](../docs/decisions/index-page-location.md): why the page lives in `games/index/`.
