# Transport server

- `7-1` A version is a whole number, and a smaller one is older. The transport server accepts the versions that a page names ([1-2](1-signaling.md)) only when each equals its own and it has each module named. Otherwise it refuses them, says which side is older and closes the connection. It compares the transport's version first and then the modules' in the alphabetical order of their names, the first difference decides, and a module that the server lacks makes the server older.
- `7-2` While a signaling connection is open, the server sends its page a check 15 seconds after the connection opened and every 15 seconds after that. When the page has answered neither of the last two checks by the time the next one is due, the server closes the connection. An answer counts when the server reads it.
- `7-3` Each signaling connection starts with 200 messages to spend and regains one every 50 milliseconds, up to 200; each message that the server reads from it spends one. When none is left, the server stops reading the connection until it regains one, and does not close it.
- `7-4` The server closes a signaling connection whose page sends a WebSocket message over 65,536 bytes, a module message that [1-10](1-signaling.md) does not allow, or a message that the transport's part on the page does not send in that state of the connection, such as a module message on a channel that the page did not name, or, before the connection has a peer ID, any message other than the versions and the answers to checks.
- `7-5` When more than 262,144 bytes that the server sent to a signaling connection have not left the server, it closes the connection.
- `7-6` The server accepts a WebSocket connection only from a page whose origin is `https://when.party`, `https://` with a host that ends in `.when.party`, `http://localhost` or `http://127.0.0.1`, each with any port or none, and refuses a connection with another origin or none.
- `7-7` A restart or deploy of the transport server closes every signaling connection. When its process fails, it tells no page, and the pages close their connections as [1-5](1-signaling.md) and [1-6](1-signaling.md) say.
- `7-8` When 250 signaling connections are opening or open, the server refuses the next WebSocket connection. The connections that the signaling deployment serves to p2p do not count.
- `7-9` When a page has not named its versions 10 seconds after the server accepted its connection, the server closes the connection.
