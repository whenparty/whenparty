# Verification

Run `sh games/platform/turn/tests/smoke.sh` from the repository root when changing TURN configuration, startup or image. It needs Docker and checks the deployed configuration with coturn's client. [The test](../tests/smoke.sh) covers public and private peers, two relayed clients, credentials in the format that the transport module gives and bad ones, and secret exposure. It is a failure-risk test of this configuration and carries no requirement IDs. [smoke-test.md](smoke-test.md) says how it runs coturn and its client.

The requirements of the transport module about TURN, such as that coturn accepts the credentials of the transport server ([8-2](../../transport/docs/specs/8-turn.md)) and relays between two pages that reach each other only through it ([8-5](../../transport/docs/specs/8-turn.md)), have browser tests of the transport module, whose runner starts coturn with `turnserver.conf` and `start.sh`, as [browser-tests.md](../../../docs/browser-tests.md) says. Run them too when changing TURN configuration, startup or image: `pnpm test:browser platform/transport` from `games/`.

[check-turn.yml](/.github/workflows/check-turn.yml) runs `smoke.sh` on every run of `games.yml` and in [ci.yml](/.github/workflows/ci.yml) when a change needs it; `ci.yml` runs the browser tests only when a package of `games/` changes, and `games.yml` runs them all before every deploy, as [checks.md](/.github/docs/checks.md) says.
