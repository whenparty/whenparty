# Return of the owner

- `5-1` When the page returns with the owner's token of its record ([9-5](9-tab.md)), it asks the rooms server over a signaling connection to return as the owner, with the term and the leaves that the record keeps (5-5). When the answer is another term ([10-7](10-server-room.md)), the page asks again at once with that term. When the answer is the term and the roster, the return succeeds, the page writes the record, and the app is told them as 5-2 says.
- `5-2` When a return of the owner succeeds, the app is told the term and, as the roster, the numbers of the server's roster that the record keeps as told "joined". Each number of the record is lost since the moment that the record keeps, or since the page started ([9-3](9-tab.md)) when the record keeps it as not lost, and the app is not told "lost". A number of the server's roster that the record does not keep is lost since the answer. The page forgets, without telling the app or the server, each number of the record that the server's roster leaves out. Whether the app was told "joined" about a number carries over from the record.
- `5-3` When a return of the owner gets no answer ([1-12](1-room.md)), or its signaling connection cannot open ([1-13](1-room.md)) or closes before the answer, the page asks again 5 seconds later.
- `5-4` When the waiting time has passed since the owner connection was lost and the return has not succeeded, the page stops returning, and the room ends for it with "owner away". The page counts from the moment that the record keeps for the loss of the owner connection. When the record keeps that the owner's page has the owner connection, the page writes the moment its return started into the record and counts from it.
- `5-5` Besides what [9-4](9-tab.md) lists, the record of the owner's page keeps the term, whether the owner's page has the owner connection or since when it is lost, each number that the page knows, with whether the app was told "joined" and since when the number is lost, and the leaves of participants that the server does not know yet. A number is in the record as told "joined" before the app is told "joined".
- `5-6` When a return of the owner gets "no room" or "removed", the room ends for the page with "owner away" when the waiting time has passed since the owner connection was lost, and with "room closed" otherwise.
