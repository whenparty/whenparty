# Snapshots

- `3-1` A snapshot holds its version, which is the host's term ([5-5](../../rooms/docs/specs/5-pages.md)) and a number; the ID and the number of the match, or none before the first match; the public number of the participant on each seat, or none; the public numbers of the spectators, in their queue's order; for each participant that has sent an action, the number and the result, accepted or refused, of its last processed action ([4-4](4-actions.md)); the room time; and the state of the match, or none before the first match.
- `3-2` The host makes changes to the game one at a time, in the order their causes arrive, and each change makes a new snapshot. The changes are an action that the host processes ([4-4](4-actions.md)); the start of a match ([5-4](5-matches.md)); a participant's arrival, a seat that a spectator takes and a participant's leave ([5-1 to 5-3](5-matches.md)); a presence event ([5-5](5-matches.md)); a deadline ([5-6](5-matches.md)); and the end of a recovery ([6-3](6-recovery.md)). The first snapshot, when the host starts the game, has number 1, and each change adds 1 in the host's term.
- `3-3` A snapshot is at most 65,024 bytes of UTF-8 as the netcode sends it, its own fields included. When the snapshot of a change would be larger, the host does not make the change, and the game stays as it was before it.
- `3-4` After each change, the host writes the new snapshot to its page's record ([5-1](../../rooms/docs/specs/5-pages.md)), and only then sends it to every participant ([3-4](../../rooms/docs/specs/3-messages.md)). When writing fails, it sends it anyway.
- `3-5` A version is newer than another when its term is higher, or when its term is the same and its number is higher. A page takes a snapshot that the host sends or publishes when its version is newer than that of the last snapshot the page took, its state passes "is state" or is none, and the rest of it has the form of 3-1. It drops any other snapshot. The host's page takes each snapshot it makes.
- `3-6` When a participant's peer connection to the host opens, its page tells the host the version of its last snapshot, or none. When the host's last snapshot is newer, the host sends it to that participant at once.
- `3-7` The controlling page of each participant gives a viewing page its last snapshot when the viewing page starts to view, and publishes to its viewing pages each snapshot it takes ([5-6](../../rooms/docs/specs/5-pages.md)). A viewing page takes them as 3-5 says.
- `3-8` The host drops a text from a participant that is neither an action ([4-3](4-actions.md)) nor the report of 3-6, and a page drops a text from the host that is not a snapshot.
