# Actions

- `4-1` A page can act while all of these hold: it controls its participant ([5-2](../../rooms/docs/specs/5-pages.md)); in its last snapshot the participant is on a seat and a match runs ([5-2](5-matches.md)); the host does not recover ([6-2](6-recovery.md)); the game has not ended for the page ([2-8](2-game.md)); and no action of the participant awaits its result (4-3). The netcode tells the page each time this changes.
- `4-2` When a page gives the netcode an action while it cannot act, or a value that is not JSON or fails "is action", the netcode sends nothing and tells the page the first of these that applies.
- `4-3` Otherwise the action gets the participant's next action number, 1 for its first action and then each time 1 more, across all its pages. The netcode writes the action and its number to the page's record ([5-1](../../rooms/docs/specs/5-pages.md)), and only then sends the host the action, its number and the match ID of the page's last snapshot. The action awaits its result until the page takes a snapshot whose last processed action number for the participant ([3-1](3-snapshots.md)) is the action's number or higher.
- `4-4` When the host gets an action whose number is 1 more than the participant's last processed action number, it processes the action: it accepts it when the participant is on a seat, the match ID is that of the running match, the action passes "is action", and "step" returns a state that passes "is state" and keeps the snapshot within the size of [3-3](3-snapshots.md). Then the state becomes what "step" returned. Otherwise it refuses the action, and the state stays as it was. Either way, the snapshot of the change holds the action's number and result.
- `4-5` When the number is the participant's last processed action number, the host sends that participant its last snapshot and changes nothing. It drops an action with any other number.
- `4-6` When an action awaits its result and the page's peer connection to the host opens again, or another page gains control of the participant and reads the record ([5-3](../../rooms/docs/specs/5-pages.md)), that page sends the action again with the same number.
- `4-7` When a page takes the first snapshot that shows an action of its participant refused, the netcode tells the page once that the action was refused, with the action.
